# Testing

## 测试策略

通过 Tower `oneshot` 调用 Axum router，使用 sqlx SQLite 内存数据库并执行真实 migrations。WHU 调用应通过可替换的 fake 隔离，测试不访问学校 API。

当前单测覆盖 migration/upsert、余额读取、限频、无效 query 的统一错误格式、日期格式、SM2 输出格式和调度时间计算。

## 用例

### 订阅与异步回填

| 场景 | 预期 |
|---|---|
| 新房间订阅 | 返回 `202 Accepted`，任务已持久化 |
| 重复订阅同一房间 | 返回 409，只有一条 Subscription |
| WHU 无该房间或请求失败 | 返回上游错误，不创建订阅 |
| 回填成功 | 状态变为 `completed`，并写入余额快照 |
| 服务重启时存在 pending/running 任务 | 任务重新排队 |

### 查询端点

| 场景 | 预期 |
|---|---|
| DB 中存在余额/日用量 | 返回 200 和记录 |
| DB 中没有余额/指定日期用量 | 返回 404 |
| 重复请求同房间同类型查询 | 间隔内返回 429 |
| 查询未来日用量或日期格式错误 | 返回 400，统一 `{ "error": "..." }` |
| 趋势日期部分缺失 | 缺失日期跳过，三个数组都返回 |
| 趋势区间没有记录 | 返回 200 和三个空数组 |
| `startDate > endDate` | 返回 400 |

### 刷新端点

| 场景 | 预期 |
|---|---|
| 正常刷新 | 调用 WHU 并 upsert 余额与当天用量，返回 200 |
| 30 分钟内重复刷新 | 第 2 次返回 429 |
| 刷新功能关闭 | 返回 503 |
| WHU 调用失败 | 返回 502 |

### 定时任务

| 场景 | 预期 |
|---|---|
| 所有订阅房间正常 | 前一天用量与当日余额 upsert |
| 单房间 WHU 失败 | 其他房间继续，该房间按配置间隔重试 |
| 前一天数据已存在 | UPSERT，不产生重复记录 |
